# .hermes.md — Tech Media Portal

## Project
Technology News & Startup Media Portal — WordPress-based, Pakistan-focused.

## Tech Stack
- WordPress 7.1 + MariaDB 10.11 + PHP 8.3 + Nginx
- Custom theme: techportal
- Custom plugin: portal-core
- Deployed at: https://techportal.24.jugaar.ai

## Key Paths
- Project root: `/root/workspace/tech-media-portal`
- WordPress root: `/root/workspace/tech-media-portal` (wp-config.php here)
- Theme: `wp-content/themes/techportal/`
- Plugin: `wp-content/plugins/portal-core/`
- Nginx config: `/etc/nginx/sites-enabled/techportal`
- Env file: `.env` (chmod 640, root:www-data)

## WordPress CLI
```bash
cd /root/workspace/tech-media-portal
wp --allow-root <command>
```

## Conventions
- CSS design tokens in `:root` of style.css (prefix `--tp-`)
- All classes prefixed `tp-` (theme) or `portal-` (plugin)
- Modular plugin architecture — features loaded via includes
- No secrets in git — .env excluded
